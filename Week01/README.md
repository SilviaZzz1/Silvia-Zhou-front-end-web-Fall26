## Inspired
[Link to ITom](https://itomdev.com/)
### What did you find?
I found ITom, an interactive portfolio website. Instead of presenting projects through a normal page with menus and cards, the website feels like a hand-drawn 3D space that you can explore. You move through different areas and discover the designer’s work as if you were walking through a small virtual environment.

### Who made it?
It was created by ITom, an interactive web developer. The website uses technologies such as Three.js to create its 3D and interactive elements.

### What caught your attention?
The first thing that caught my attention was the visual style. Everything looks like a rough black-and-white sketch, but at the same time the environment is interactive and three-dimensional.
I also really like the way the website organizes information. Instead of simply clicking a navigation bar to go from one page to another, you explore different spaces. It makes the portfolio feel less like reading a website and more like discovering someone’s personal creative world.

### What would you like to understand about how it works?
I would like to understand how the hand-drawn visual style is created and combined with the 3D environment. I’m also curious about how the transitions between different spaces work and how Three.js is connected with the regular HTML elements and interactions on the website.
