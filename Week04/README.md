## Interesting Website
[⁠Michael Lo](https://www.vvichael.com/)
What made me notice this website is how the layout changes the way I explore the work. Instead of just scrolling through a normal vertical grid, the desktop layout moves horizontally and feels more like moving through a board or exhibition. I also like how the same projects can be reorganized between list and grid views. When the screen gets smaller, the layout changes into a vertical structure, so the relationship between the elements changes depending on the available space.
