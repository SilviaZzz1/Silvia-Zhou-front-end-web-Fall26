## Interesting Website
[Studio Freight](https://studiofreight.com/)
I chose Studio Freight. The website feels bold and editorial to me. The first thing I noticed was the oversized typography and the amount of empty space around it. The layout is also asymmetric, so it doesn’t feel like a typical grid-based company website. The colors are mostly neutral, which makes the project images stand out more. I also like how the scale of the typography creates a really strong hierarchy. Even before reading the content, the website already feels like a creative design studio rather than a traditional corporate website.
